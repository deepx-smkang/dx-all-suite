Cloud Compile Pipeline

S3

컴파일 파이프라인은 Greengrass Solution 스택이 프로비저닝합니다. 스택 배포 후 aws configure로 자격 증명을 설정하고, .onnx와 .json 설정을 S3 모델 버킷에 업로드하면 컴파일된 .dxnn이 같은 디렉터리에 생성됩니다. The compile pipeline is provisioned by the Greengrass Solution stack. Once the stack is deployed, set credentials with aws configure, upload your .onnx and .json config to the S3 model bucket, and the compiled .dxnn appears in the same directory. El pipeline de compilación lo aprovisiona la pila de Greengrass Solution. Una vez desplegada, configure credenciales con aws configure y suba su .onnx y .json al bucket S3 de modelos: el .dxnn compilado aparece en el mismo directorio. コンパイルパイプラインは Greengrass Solution スタックがプロビジョニングします。スタックのデプロイ後、aws configureで認証情報を設定し、.onnxと.json設定をS3モデルバケットにアップロードすると、コンパイル済み.dxnnが同じディレクトリに生成されます。 编译流水线由 Greengrass Solution 堆栈预置。堆栈部署完成后，使用aws configure设置凭证，将.onnx和.json配置上传到S3模型存储桶，编译好的.dxnn会生成在同一目录中。 編譯管線由 Greengrass Solution 堆疊佈建。堆疊部署完成後，使用aws configure設定憑證，將.onnx和.json設定上傳到S3模型儲存貯體，編譯完成的.dxnn會產生在相同目錄中。 

aws configure
aws s3 cp yolov5-s-face_640x640.onnx s3://<model-bucket>/
aws s3 cp yolov5-s-face_640x640.json s3://<model-bucket>/
aws s3 cp s3://<model-bucket>/yolov5-s-face_640x640.dxnn .

Thing Group & ZTP

IoT Core

디바이스를 Thing Group에 등록하면 NPU 드라이버·펌웨어·dx_rt·dx_stream이 자동 설치(Zero-Touch Provisioning)되어 별도 수작업 없이 엣지 배포가 완료됩니다. Register a device to the Thing Group and the NPU driver, firmware, dx_rt, and dx_stream are installed automatically (Zero-Touch Provisioning) — edge deployment completes with no manual steps. Registre un dispositivo en el Thing Group y el controlador NPU, el firmware, dx_rt y dx_stream se instalan automáticamente (Zero-Touch Provisioning), completando el despliegue edge sin pasos manuales. デバイスをThing Groupに登録すると、NPUドライバー・ファームウェア・dx_rt・dx_streamが自動インストール（Zero-Touch Provisioning）され、手作業なしでエッジ展開が完了します。 将设备注册到Thing Group后，NPU驱动、固件、dx_rt和dx_stream会自动安装（零接触配置），无需手动操作即可完成边缘部署。 將裝置註冊到Thing Group後，NPU驅動、韌體、dx_rt和dx_stream會自動安裝（零接觸佈建），無需手動操作即可完成邊緣部署。
